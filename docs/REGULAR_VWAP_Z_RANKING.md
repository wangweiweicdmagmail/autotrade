# 常规时段与VWAP归一化排序（2026-11-24）

用户最新要求替代此前盘前盘后预热和30／50／20评分方案：股票只用常规交易时段数据，趋势榜只按标准差归一化的位置排序。

## 数据时段

股票一分钟、五分钟的默认输入均为TradingView `regular`，不包含盘前、盘后或夜盘。两个周期的EMA、ST、ATR、TD与其他本地PineTS指标使用相同的常规时段K线。标准EMA仍连续使用此前常规交易日的真实K线，不每日重置，也不生成虚假预热数据。

股票VWAP使用HLC3及成交量加权，从当日09:30常规时段首根开始累计；σ是同口径的成交量加权总体标准差。第一根的σ为0，不能生成归一化排名；后续存在有效非零方差时才参与。没有新增等满15分钟或30根历史的排名条件。

NAS100、SPX500、WTI继续使用数据商`default`，请求不传股票的session属性。指数VWAP与其原日线会话锚点不变，不在美股09:30重新计算。独立夜盘模拟继续显式选择24h，并沿用独立SimBroker及确认要求。

生产默认由`config.TV_MARKET_SESSION`声明，Node默认由`market_session.js`统一声明为regular。显式extended／24h历史输入兼容仍保留；这些输入的结果不能混入当前regular榜单。股票TV图表也需切到常规时段才能做同源对照。

## 唯一排序值

直接使用一分钟K线close，每根一分钟K线确认收盘后计算：

`Z = (close − VWAP) / σ`

`score = abs(Z)`

- Z > 0：位于VWAP上方；Z < 0：位于下方；Z = 0不进入趋势榜。
- 所有符合数据要求的个股按|Z|降序合并取前十；同值仅按股票代码排序，保证稳定。
- |Z|可以小于1，不要求先突破外轨；原突破段与回踩事件只作观察，不参与排序或资格过滤。
- 不再累计外轨保持率、趋势段成熟度、轨道速度、最大回撤质量；也不叠加EMA9斜率或15分钟分类成功率。
- 当前回撤通过close相对VWAP位置的变化直接反映到Z；不继续使用此前趋势段的峰值分数。这是当前归一化距离，不是速度或盈利概率。
- 参考指数、QQQ／SPY及原ETF参考名单不参与个股排序。股票池和原参考名单不变。

排名只消费本地确认序列中同一根的close／VWAP／σ与Z。未收盘或未来数据不参与；标准差无效、缺口或错根不补造分数。不依赖五分钟EMA／ATR评分数据，也不因为它们尚未计算完成而阻挡当前一分钟排名。

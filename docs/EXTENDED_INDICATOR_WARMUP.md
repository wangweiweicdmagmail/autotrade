# 一分钟与五分钟统一盘前盘后预热（2026-11-22）

2026-11-24已由[常规时段与VWAP归一化排序](REGULAR_VWAP_Z_RANKING.md)替代。股票一分钟与五分钟默认改回regular；本页extended预热口径作为历史记录保留，不是当前启动配置。

2026-11-23展示边界更新：按[盘前观察榜](PREMARKET_RANKING.md)在盘前接纳有当前收盘K线、评分齐备的观察子集并标记缺数；开盘后恢复全池完整批次。下文“盘前只预热、不更新榜单”为旧展示口径。指标预热及全部新开仓仍限常规盘的边界不变。

用户选择股票两个周期都使用TradingView **extended（盘前盘后，不含夜盘）**。默认由`config.TV_MARKET_SESSION`统一声明，主采集器同一参数传给一分钟与五分钟请求；WTI、NAS100、SPX500继续省略时段参数，使用服务端默认时段。未确认extended的响应不能当成盘前盘后数据接收。独立夜盘模拟仍由本次运行参数选择24h，不修改其契约。

## 计算与交易分开

| 对象 | 新计算口径 | 原交易边界 |
|---|---|---|
| 五分钟Pine指标、真正EMA9 | 输入真实盘前盘后K线，固定原参数，跨日连续预热 | 不注册开盘重置EMA，不更换策略模型 |
| 一分钟EMA7、EMA3、ST（10，4）／ST（10，3）、ATR、TD | 全部消费真实盘前盘后数据；09:30不清空递推状态 | 不因此允许盘前新开仓，ST跟踪仍只发布常规盘确认参考 |
| 股票VWAP与±1σ | 标准Session口径，HLC3成交量加权，从当日扩展时段首根真实K线开始累计；正常美股为04:00开始，次交易日重置 | 保留已授权的中线方向、可选外轨过滤，不增加触线交易要求 |
| VWAP分布七分钟速度／30分钟VWAP速度 | 使用扩展时段EMA和同一VWAP；09:30可参考09:23或09:00的真实值 | 精确参考时刻缺失时显示未就绪，不补价格 |
| 候选趋势段与分类成功率 | 轨道、EMA、TD由盘前预热；展示与趋势段统计仍从09:30开始；分类仍用最近15分钟常规盘真实收盘样本 | 开盘不足15分钟按实际样本数，不将盘前样本计入分类保持率 |
| 开盘三连线预约 | 外轨取同一份已预热VWAP；三根信号K线仍只能来自常规盘前五分钟 | 每天两笔、三分钟保本、09:45退出及公共准入不变 |
| 昨日高低点 | 保留常规盘日线数据 | 不用扩展时段高低点替换既有昨日区间 |

VWAP是归一化参考标尺；是否允许开仓仍按明确的准入与策略规则决定。本次不取消此前确认的双参考方向过滤，不增加ST/FVG自动退出权限，不修改风险预算、订单归属、券商接口或外部订单守卫。

## 历史、缓存与完整性

- 一分钟默认预载4000根（原850根）。扩展时段一天最多960分钟，需要覆盖昨日完整常规盘、盘前和更早预热。不是要求每只股票每分钟必须成交。
- 盘前稀疏K线按真实根数预热，不补分钟。常规盘已知分钟缺口仍标记并排除，维持原准入保护。
- VWAP需要覆盖本交易日扩展时段开头；输入从中午截断时不冒充完整Session轨道。载有前一交易日的历史或包含04:00起点时，可在首个真实报价开始累计。
- 一分钟时间换算结果使用有界内存缓存，避免4000根历史在每次报价时反复做时区转换；缓存只保存时刻的时段属性，不缓存或伪造价格。
- 常规盘之外继续预热，但候选榜显示仍保留上一常规盘结果，不用盘前日期清空昨日榜单。
- 评分模型升级为`ema9_15m_v3`，权重保持VWAP结构30%、EMA9斜率50%、分类20%。旧v1/v2缓存等待重建，不能与新时段数据混用。每条感知序列的`source.session`记录实际时段；确认ST快照的`session`为extended，旧regular历史快照只保留读取兼容。
- 本地五分钟回测原本使用extended缓存，本次不删除或改写缓存。重新调整人工启动时刻继续复用计算结果。旧regular历史输入可显式指定regular重放，不能据此声称已经包含盘前。
- 指数保留默认时段与数据商日线会话锚点，不在09:30重置；股票的新配置不套用到指数。

## TradingView对齐条件

TV图表也要选择盘前盘后extended。常规时段、extended、24h是三种不同输入，不能只看指标名称相同就认定数值一致。还需统一数据源／交易所、K线周期、价格源、参数、复权及高周期确认设置。

`indicators/vwap-ema7-position-1m.pine`与`indicators/vwap-outer-pullback-1m.pine`采用标准`ta.ema`、`ta.supertrend`、`ta.atr`及`ta.vwap(hlc3, timeframe.change("D"), 倍数)`口径；首个加载bar单独初始化VWAP。根内修订仍以同一根最终close/OHLCV重算，不重复累加权重。PineTS短样本EMA初始化与现有JS首close种子有短暂差别；生产完整预热后核对，不承诺历史不足时逐根相等。

只读核对发现现有TV布局混有regular和extended。代码不会在后台切换用户图表时段；需要把用于对照的图格设为extended。本次没有编辑TV指标或模拟／实盘账户。

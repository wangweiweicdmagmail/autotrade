# 交易影子Agent：规则摘要、提示词与首版方案

日期：2026-11-23。状态：研究方案与可复用提示词，尚未启用影子推理或模拟下单进程。本文件不改变任何实盘准入、风控、保护或退出规则。数据和逐单解释沿用[研究系统约定](AGENT_TRADING_RESEARCH.md)，实施进度见[M1／M2](AGENT_TRADING_RESEARCH_M1_M2.md)。

## 系统目标及三层规则

跟随NAS100、SPX500的方向与节奏，从前十候选中选择更好的个股机会。榜单负责减少遗漏，具体交易判断来自大盘节奏、个股位置、短期动量和风险条件的组合。用户通常只选择一至三只交易，这是观察与选择偏好，不是现行系统的固定持仓笔数上限。

| 层次 | 已确认含义 | 不得混淆 |
|---|---|---|
| 趋势感知 | 从突破VWAP外轨开始评价延续，回到中线同侧仍可保留趋势段；越过中线到反侧结束该段 | 感知状态改变不自动平仓 |
| 候选与准入 | 前十、趋势同向、确认TD和实时价格位置，以及有效风险和保护 | 上榜不是入场脉冲，高分不是盈利概率 |
| 交易决策 | 大盘压力／支撑、趋势启动、回调后延展、个股相对强弱与入场位置 | 这些语义判断尚未全部量化；未知的人工思考必须询问 |

### 当前代码的硬规则

以[近期功能](FEATURES_2026-11-21.md)、[风险规则](RISK_LIMITS.md)、[统一预热](EXTENDED_INDICATOR_WARMUP.md)和实际运行配置为准：

- 股票一分钟／五分钟使用extended，指数使用default；计算预热不扩大开仓时间。
- 确认一分钟close同时在VWAP中线和确认五分钟EMA9上方定义多头，同时在下方定义空头；夹在中间或相等为中性。
- 评分v3为VWAP结构30%、五分钟EMA9归一化斜率50%、最近15分钟分类成功率20%。乖离只作位置参考。
- 全部新开仓必须在有效前十、同向，确认一分钟TD做多≥1／做空≤−1；TD比较跨度为4，图形着色±3不等于下单门槛。
- 下单时实时价还须在确认VWAP中线和真正五分钟EMA9的同向侧；不能把旧兼容字段中的EMA7当成EMA9。
- 每笔候选订单若启用外轨过滤，必须在对应外轨外；“回到VWAP中线就是好位置”不能绕过这项检查。Agent可以指出冲突并记录待研究规则，不能自动关闭过滤。
- 手动初始止损可选五分钟2×ATR且位于当前K线极点外，或沿亏损方向1σ；自动／信号订单保留其策略止损。
- 当前预算为单笔1000美元、总剩余风险2200美元、多空各1100美元、单股总名义仓位不超过净值140%；必须读取当前配置，不能永久写死这些数值。保本后剩余风险为零，未知受理和未成交仍占风险。
- 候选定时保本排除入场分钟，再数完整一分钟确认收盘；跟踪止盈只收紧不放宽。已明确启用ST（10，3）跟踪的候选批次有专属反向退出规则；其他ST／FVG反向仅提醒。分布图ST（10，4）不能代替保护ST。
- 唯一交易入口仍是控制台。影子Agent没有实盘交易权限，也不调用外部订单守卫或接管接口。

### 尚需从用户解释中学习

大盘触及哪一层压力／支撑才有交易意义；两个指数不一致时怎样选择；同向候选之间如何取舍；何时可以追第一波、何时必须等回调；怎样决定提前保本、减半、继续持有或全平。不得仅从单笔盈利猜出这些偏好。

## 逐单研究的使用边界

原订单中的名次和TD属于当时证据，不能用最新收盘榜单或修改后的评分去替代。实际订单样本可能同时出现低名次、较小同向TD的盈利交易，以及高名次、较大同向TD的亏损交易。因此名次与TD应作为候选和时机信息，不能直接解释为盈利概率。

需要验证的假设包括：名次不应成为机械只选第一的规则；TD应描述同向动量；不能自行规定“TD到9就反手”。研究样本和当前快照中的具体交易及盈亏仅保存在本机研究目录，不随代码和通用提示词发布。

旧评分、extended预热或参数调整后的历史重算，不代表原订单当时所见。缺少整日原榜单、滑点、费用和用户解释时，不输出“Agent当时会赚更多”的结论。休市时保留的收盘榜单不是当前可交易信号。

## 可直接使用的系统提示词

```text
你是AutoTrade的交易影子研究员。目标是在相同数据、资金和成本口径下，
学习用户跟随大盘节奏选择个股的交易方法，先记录独立计划，再与实际订单比较。
你只能写研究计划和模拟记录，没有实盘开仓、改单、撤单、平仓或修改配置的权限。

一、输入与时间
1. 以工具提供的as_of和实际观察时间为边界，先核对交易时段、数据质量、
   当前一分钟确认批次、五分钟确认时间和运行配置。
2. 使用TV K线和本地PineTS已有输出，不另写指标公式。
3. 只用该时刻已知数据；未收盘值只作观察，不冒充确认信号。
   盘后重算或补取的数据不能当作历史时刻已经知道。
4. 休市、报价陈旧、批次不齐、必要指标缺失时输出WAIT和具体原因。
   禁止使用当前收盘榜单倒推当日早些时候的机会。

二、推理顺序
1. 先描述NAS100和SPX500：方向、VWAP/±1σ位置、轨道推进、
   昨日高低点、近期回调和突破。区分可观察事实与推断。
2. 再比较有效前十候选：趋势方向、评分拆解、上榜时间、
   趋势段持续性、EMA9斜率和分类、乖离、回撤与恢复、确认TD。
3. 将机会标为趋势启动、回调后延展或暂不交易。说明大盘节奏与个股节奏的关系；
   指数分歧、个股追价过远、位置没有优势时优先等待。
   这些判断是待验证策略，不得伪装成已经验证的统计优势。
4. 候选排名仅提供观察资格；不能仅因排名第一或TD绝对值大就建议进场。
   TD是动量状态；不得凭TD到9自行认定超买超卖或反向交易。

三、确定性准入
1. 使用公共准入的只读结果，不由语言模型裁定“强制通过”。
2. 核对当前前十和方向、TD多≥1/空≤−1、实时价相对确认VWAP与真正五分钟EMA9、
   每笔外轨过滤、交易窗口、价格时效、止损合法、数量和风险预算。
3. 任一硬条件失败：只输出WATCH/WAIT，列出缺项与下一次要等的事实。
   不关闭外轨过滤，不修改止损模式、风险或全局保护选项。
4. 读取实际生效的止损模式和候选保护设置。
   风险定量和预览由复用现有规则的只读计算器提供，不能自行杜撰股数。

四、交易与持仓计划
1. 只给出少量有位置和节奏依据的候选。每个计划必须有触发、参考价、
   初始止损、风险、失效条件、保护/退出方案、到期时间和证据引用。
2. 没有机会时明确WAIT，不为每天凑笔数而交易。
3. 管理影子持仓时，沿已记录的规则处理保本和追踪，只收紧不放宽。
   任何自主减仓/退出建议明确说明其依据与“待验证”身份。
4. 普通ST/FVG转向不能成为调用实盘退出的理由。

五、学习与隔离
1. 独立影子决策在结果和人工下单曝光前持久记录。
   当日人工入场不能成为独立影子Agent跟随开仓的依据。
2. 辅助人工持仓管理可以读取人工持仓，但该通道单独评价，
   不把它的结果当作独立发现机会的成绩。
3. 盘后比较相同机会的发现时间、方向、位置、初始风险、保护、
   减仓/退出、实际和模拟结果，保留漏单、误报、未触发和放弃计划。
4. 用户的每个不明确动作都登记稳定问题ID，读取已有答复后再问；
   不把你的推断存成用户确认方法。方法修改保留版本和反例。
5. 不能仅因超过100笔或某日盈利就声称已学会、优于人工或可自动实盘。

输出必须包含：
as_of、数据版本、规则版本、mode=shadow、
decision=WAIT/WATCH/PROPOSE_ENTRY/PROPOSE_MANAGEMENT、
大盘事实、个股事实、逐项硬条件、判断及反证、
计划/失效/保护、证据引用、仍需核实的问题。
不输出无来源的胜率或置信概率。
```

## 首版开发范围

建议先做“影子建议记录”，与M3同源回放逐步对接，不一次实现自主交易：

1. 每个完整一分钟收盘批次生成精简上下文。只读当前榜单、TD、大盘、局部行情、配置和影子自身持仓，固定数据及规则版本。
2. 当大盘触位、候选进入/退出、动量恢复或影子持仓需要决策时推理；平静分钟只更新状态，避免每分钟重复调用大模型。相同事件和计划去重。
3. 先持久保存不可事后改写的计划，再推进独立模拟。第一版没有未来可用的根内数据时保留成交顺序歧义，不假造精确触价。
4. 维护独立影子账本和SimBroker，不创建生产OrderManager或IBKR网关，不将模拟单交给正式外部订单守卫。
5. 每天自动生成“人工 vs Agent”比较，接入复盘研究页；用户解释继续写现有questions.jsonl，方法仍需确认和验证。

新增的context／plans／simulation／comparison接口属于待开发能力，不能把本提示词当作已经运行的影子引擎。当前可用的是M1/M2查询和复盘研究页；`/api/auto`、`/api/lots`及外部守卫不是影子执行接口。

## 比较方法

分两条实验线，结果不可混算：

- **独立机会选择**：Agent只根据当时数据决定自己的入场和退出，盘后再看人工订单；比较发现延迟、漏掉的趋势、误报、净R、回撤和风险占用。
- **相同入场的管理对比**：固定用户实际入场，只比较保本、减仓和退出；这是退出管理实验，不能宣称Agent会独立找到该笔交易。

周五可用来解释和提炼规则，后续未参与提炼的日期用于评价；每次尝试保留记录。反复在同一批订单上挑最优参数会增加过拟合风险，参见原始研究[The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。日内同一行情的多笔订单也不能简单视为互相独立样本。

启用影子建议前的最低验收：未来数据不改变过去计划、计划先于模拟成交保存、重启不重复计划、数据缺口明确阻断、相同输入可重放、没有任何真实交易调用。收益比较还需统一费用、滑点、机会集和资金约束。是否启用实盘执行由用户根据后续证据单独明确授权。

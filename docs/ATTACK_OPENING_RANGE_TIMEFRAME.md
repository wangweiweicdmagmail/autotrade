# 五分钟进攻区域：开盘十五分钟区间跨周期修复

2026-11-22，本地版本由17.0升级为18.0。TV源码为[attack-5m.pine](../indicators/attack-5m.pine)，PineTS运行副本为[pinets/attack.pine](../indicators/pinets/attack.pine)，两份完全一致。

## 根因与修复

旧实现用`regularBarCount < 3`按当前图表周期计数。五分钟图正确覆盖09:30、09:35、09:40三根；一分钟图只覆盖09:30、09:31、09:32，在09:33就把后续十二分钟排除。

新实现按美东固定窗口`09:30 <= K线开盘时刻 < 09:45`累计真实高低点，窗口最后一根确认收盘时锁定。若窗口最后一分钟没有报价，在窗口后的首根到来时锁定；不补价格。09:45及之后K线的高低点不能改变区间。窗口形成中继续导出已有真实高低点，归一化`Opening3_Distance`等窗口锁定后才提供。

| 图表周期 | 累计开盘时间 | 正常完整行情根数 |
|---|---|---:|
| 一分钟 | 09:30～09:44 | 15 |
| 五分钟 | 09:30、09:35、09:40 | 3 |

脚本也允许能完整切分十五分钟的三分钟与十五分钟周期；十分钟等跨越09:45边界的周期明确拒绝，避免混入窗口外价格。区间以图表提供的真实OHLC为准，不能借此恢复数据源未提供的价格。

同时修复两个相关周期问题：盘前窗口改为`04:00 <= time < 09:30`，一分钟09:29那根也参与；纯常规盘图表跨日时，即使前后两根都属于常规盘，也能识别新交易日第一根并重建当天图形。日期按America/New_York识别，不依赖固定UTC开盘时刻。

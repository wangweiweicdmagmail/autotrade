# TD 序列分时线

源码：[td-price-line.pine](../indicators/td-price-line.pine)。这是独立的行情观察指标，当前不注册为自动执行的策略模型。

在 TradingView 切换到标准一分钟图，打开 Pine Editor、新建指标、粘贴源码，保存并添加到图表。隐藏主图原来的价格线或K线，只保留本指标，可直接观察彩色分时折线。其他指标是否显示由用户选择，不自动修改图表。

## 价格与颜色

折线直接使用 `close`，不做均线平滑。历史点是每分钟收盘价；未收盘段统一黄色虚线和黄色空心端点，仅随最新报价移动，不计算预估TD。历史一分钟数据不能还原分钟内部的逐笔轨迹。

每根K线收盘时，默认比较 `close` 与 `close[4]`：

| 当前比较 | 连续计数 | 默认颜色 |
|---|---|---|
| 高于四根前收盘价 | 同向时正数加1，反向切入时从+1开始 | 计数≥+3为绿 |
| 低于四根前收盘价 | 同向时负数减1，反向切入时从−1开始 | 计数≤−3为红 |
| 两者相等，或历史不足 | 归零 | 灰 |
| 计数为−2、−1、0、+1、+2 | 未达到趋势阈值 | 灰 |

着色阈值默认3；比较跨度默认4；线宽默认3。三者及颜色可在参数中调整。条件以收盘价和四根前收盘价的比较为准，与本根K线是阳线还是阴线无关。计数可以超过9，不在9后回绕，也不绘制13倒计数；它是基于TD比较思想的趋势着色，并非完整原版TD Sequential或衰竭买卖提示。

已确认颜色按该根最终TD决定通向其价格点的线段。只有 `barstate.isconfirmed` 时才更新计数；未收盘根的TD与Direction保持最新确认值，价格变化不能改变它们。黄色虚线使用独立绘图，收盘后由最终红绿灰实线接替。没有使用 `varip` 或未来数据。

时段跟随图表输入，计数不主动按日重置。开启盘前盘后时，这些K线也参与比较；只看常规盘时在TV图表中选择常规交易时段。非一分钟图表明确报错，不静默改变计算周期。

## 数据窗口与执行边界

- `TD_Price`：已确认的彩色折线价格；未收盘根为`na`，由独立黄色尾段显示实时价格。
- `Forming_Line` / `Forming_Price` / `Forming_Point_Inner`：黄色虚线、端点和空心效果，仅用于图形显示，不参与TD计算。
- `TD_Count`和`TD_Count_Confirmed`：均为最新已收盘根的有符号计数；未收盘不更新。
- `Direction`：已确认绿色为1，红色为−1，灰色为0；当前黄色尾段没有额外方向判断。
- `Entry_Signal`始终为0；`Entry_Price`、`Long_Stop`、`Short_Stop`、`ATR`均为`na`，尚无入场及止损规则。

未修改模型注册表、行情订阅、现有指标或实盘执行代码，也不创建入场计划。后续接入前再明确交易规则并完成模型声明。

## 确认值与榜单（2026-11-20补充）

控制台前十榜在每个股票名称旁显示 `TD +N`、`TD -N` 或 `TD 0`，采用共同确认时刻对应的最新收盘值，着色阈值仍为±3。锁定历史光标不改变榜单读数；缺少有效计数显示 `TD —`，悬停可查看确认分钟。榜单排序和原趋势方向不因TD标签改变。

宫格通过独立的 `rhythm_price_1m` 原始报价显示当前EMA3黄色尾点，未把实时点或预估值写入TD序列。TV指标源码已经同步修改；初版由用户确认显示正确，新增黄色尾段的PineTS隔离检查已通过，尚待用户在TV替换源码后验收。


## 开仓TD门槛（2026-11-20）

在前十候选且同向的基础上，全部新开仓要求多头TD≥1、空头TD≤−1（2026-11-21调整，含±1）。使用最新共同确认分钟的整数计数，未收盘不预估；数据缺失或错位按不达标处理。折线与标签着色阈值仍是±3，比较周期仍是4，开仓门槛独立配置为1。TD回落只影响后续新开仓，不自动操作已有仓位、保护单或已受理订单。Python只读取现有Node计数，不另算TD。开仓卡片只保留轨道市价，以✓/✗逐项列出TD、五分钟EMA9位置及其他准入条件与检查值；完整边界见[候选准入](MARKET_RHYTHM.md#全部新开仓的候选准入)。

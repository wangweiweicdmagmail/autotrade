# 开盘重置 EMA9 · 五分钟独立观察指标

源码：[session-ema9-5m.pine](../indicators/session-ema9-5m.pine)。这是2026-11-22新增的独立观察指标，不在策略模型注册表或本地实盘计算清单中，不改写原EMA9、候选榜、开仓过滤或持仓保护。未连接TV编译；由用户先在自己的图表观察。

## 确定的计算规则

- 只接受五分钟图表，其他周期给出明确错误。
- 面向美股常规盘，使用TV的`session.ismarket`并限定`America/New_York`的工作日09:30–16:00窗口；盘前盘后不计数、不参与计算、不画线。美东夏令时由时区处理，不能按北京时间或固定UTC开盘时间重置。
- 每天首根09:30 K线的close作为所有当日EMA的初始值。第一根形成中数值随close变化；收盘时等于首根最终收盘价，不使用当天开盘价或昨天的EMA。
- 令当天实际出现的常规盘K线数为n，选用周期`N=min(n,9)`。第1根读EMA1、第5根读EMA5，第9根及之后一直读EMA9。
- 每个固定周期L的当日EMA独立从首根close开始：`E(L,1)=C1`；后续`E(L,k)=2/(L+1)×Ck+(1−2/(L+1))×E(L,k−1)`；对外值为`E(min(n,9),n)`。
- 实现用同一个函数的九次独立调用维护EMA1–EMA9，因此第5根等于将当天五个close按固定周期5重算的结果。不是拿上一根EMA4改变系数继续递推；九条状态不是九份TV订阅。
- 分钟空缺只表示少了一根真实K线，不补价格、不按墙钟推算根数。若加载历史缺少当天09:30首根，则当日等待、不将中途第一根冒充开盘；需要加载完整当日历史。晚于09:30才首次成交的IPO等特殊开盘暂不在本观察版范围。
- 第9根由EMA9状态直接选出，第10根继续同一条EMA9。前期选取的周期逐根变化，会改变均线响应，跨周期的相邻输出差并非固定EMA9斜率，不直接用于现有榜单评分。

普通`var`状态按K线回滚和提交；同根多次报价从上一根已确认状态重新计算，不按tick累计根数或重复平滑。未收盘值会变化，历史最终值使用最终close；不声称历史OHLC可还原每一笔根内报价。脚本重新加载时从当天开盘重放，历史输入相同就得到相同结果。

## 图表和数据窗口

图表显示一条青色均线，颜色和宽度可调；当前未收盘线段降低不透明度。首根close显示圆点，每日之间断开；即使图表不显示盘前盘后，也不会将昨收和今天首根连成趋势。

| 导出标题 | 含义 |
|---|---|
| `Session_EMA` | 当前选中的当日EMA，盘前盘后或开盘历史不足时为na |
| `Session_Bars` | 当日真实五分钟K线数，包含当前形成中的一根；时段外为na |
| `Effective_Length` | 本根选中的周期1–9；时段外为na |
| `Session_Ready` | 本根可显示为1，否则0 |
| `Entry_Signal`、`Direction` | 固定0，未定义交易信号或方向 |
| `Entry_Price`、`Long_Stop`、`Short_Stop`、`ATR` | 固定na，不提供入场计划或策略止损 |

`Session_EMA_Line_A/B`是交替绘制不同交易日的内部线，`Session_First_Close`为首根圆点，仅在图形显示。数据窗口统一读取`Session_EMA`。本指标没有可执行交易语义，因此不生成或登记模型声明、不申请任何指标订阅、不下单。

## 放到TradingView观察

1. 打开美股普通K线图，周期选五分钟。可以显示常规盘或扩展时段；指标自身只取常规盘。
2. 新建独立Pine指标，粘贴完整源码，保存并添加到图表。
3. 打开数据窗口，查看当天09:30首根：`Session_Bars=1`、`Effective_Length=1`、`Session_EMA=该根close`。
4. 检查第2至8根的实际周期，以及10:10这根（正常连续行情中的第9根）起周期保持9。K线标记时间为开盘时间，10:10这根在10:15收盘。
5. 检查高开、低开和相邻交易日，确认没有承接昨日EMA；开启盘前盘后后，常规盘相同K线的结果应不变。
6. 检查最新未收盘K线，数值应随close更新，根数保持不变；刷新后确认历史值相同。缺少当日开盘数据时先向左加载历史。

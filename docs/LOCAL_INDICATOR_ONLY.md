# 指标计算统一为本地 PineTS（2026-11-22）

当前唯一指标计算链路为：**TradingView K线 → 本地 PineTS → 实时／收盘确认快照 → 现有执行模型**。项目不再向 TV 注册指标，不再下载私有指标元数据／加密正文，也不提供云指标失败后的自动回退。

## 各入口现状

| 入口 | 当前行为 |
|---|---|
| 正式控制台 | `tv_cloud_daemon.js` 只订阅五分钟、一分钟和日线；PineTS worker 计算指标，TV指标订阅数固定为0 |
| 历史回测 | 原 K线／本地计算缓存继续使用，不删除已有研究数据；人工启动时间只影响执行回放 |
| 历史导出／`cache_day.py` | `dump_trend_state.js` 改为拉K线和日线，再调用共享 PineTS 计算模块，保留逐根导出字段 |
| 夜盘模拟 | 独立一标的K线会话与独立本地worker，只计算所选五分钟模型；仍使用SimBroker，不接实盘订单管理 |
| 收益对比 | QQQ日线只经K线请求获取，不再创建空指标配置文件或调用云指标加载器 |
| 一次性CLI／`npm --prefix service run collect` | `tv_cloud.js` 仅导出K线，旧`--indicators`参数明确拒绝 |
| 本地诊断 | `python3 service/tv_diag.py` 检查凭据文件、PineTS依赖及本地源码可加载性，不请求TV指标接口 |

正式五分钟worker目前计算原有七个基础指标与黄金信号；一分钟VWAP回踩在独立的一分钟worker中计算。启动进度统计本地实际模型数，不再等待云端脚本正文。

## 已移除的旧实现

- 主采集器中的TV Study创建、元数据下载、独立注册重试、250毫秒Study轮询，以及七合一／EMA7云端对照分支。
- 旧`pine_text.js`、`refresh_pine_texts.py`、云指标注册表`indicators.json`、v4备用采集器、旧云端探测及抓帧脚本。
- 旧EMA7云端影子对照模块与只验证旧正文协议的测试。交易研究中的“影子交易”功能保留，它是执行模拟，与云指标订阅不同。
- 加载页的云正文版本不匹配、修复正文缓存按钮、相关后台方法与接口；旧修复URL返回404，不再执行脚本。
- `config.py`中的旧私有WS端点、游客令牌和`PINE_INDICATORS`云指标注册配置。

`--benchmark-study`、`--ema7-shadow-*`旧启动参数在读取凭据或连接网络前即拒绝。遗留影子对照环境变量不再启用任何订阅。

旧`CloudDataCollector`和`TradingViewDataCollector`名称只保留立即报错的兼容壳，没有网络或注册代码。历史`main.py`默认在连接券商前拒绝运行并指向`run_console.sh`；仅显式选择mock时可作旧流程演示，不把生产数据故障静默降级为模拟行情。`auto_runner.py`沿用当前本地采集器。

## 保留的契约与数据

- `service/pine_strategies.json`仍是本地模型声明，`indicator_id`、`local_only`及`e9/e9_c`等既有字段保留兼容；这些字段不再决定任何TV注册行为。
- 原始Pine源码、参数、plot映射、策略信号和执行配置保留；没有在Python复制指标判断或改变订单入场、保护和退出规则。
- 原有K线、指标结果、审计与回测缓存保留。被移除的是云端加密正文缓存流程，不是本地回测缓存。
- TV账户仍用于访问K线及其行情权限；[首次登录引导](TRADINGVIEW_LOGIN.md)保留。用户自己在TV图表中显示的指标不由本次清理删除。
- `study_health`及其部分返回字段仅作为现有调用方的兼容名称，监测对象已明确为本地计算错误与确认快照完整性，不再监测云Study协议。

## 共享计算与隔离

`local_snapshot.js`统一将本地PineTS结果转换为原快照字段；`local_history.js`复用`pinets_runtime.js`做逐根批量计算。夜盘复用`createLocalIndicators`的相同时间对齐和陈旧保护，独立选择模型及历史输出长度，不复制策略公式。

夜盘先预载足够K线（请求601根，至少401根预热），页面仍只展示最近200根。只有所选模型的实时值与当前K线、确认值与前根K线匹配时才发布对应值；计算落后时不拿旧指标配新价格。`24h`依旧必须由服务端明确确认，未确认不能启动模拟交易。报告明确记录`source=pinets`、本地版本与输入来源。

服务端模块修改需要重启控制台及其行情子进程加载；仅刷新页面不能替换旧Node进程。调整指标时更新本地源码并验证，TV图表保存新版不会通过旧注册链路自动替换本地代码。

## 验证范围

隔离验证覆盖：主采集器在禁止Study／指标元数据API的桩中启动；旧参数拒绝；K线完整性、时段校验与会话清理；夜盘仅计算所选模型，实时／确认值与直接PineTS逐根一致；历史导出时间与模型字段一致；已退役Python入口不能连接网络或静默使用mock。

# 开盘小区间归一化位置：独立研究指标

2026-11-24。本页说明共用Pine观察指标及离线研究入口。正式前十榜也使用同一中点半宽公式；VWAP开仓准入与持仓保护保持原规则。研究命令无需启动正式控制台或券商。

## 指标定义

当前研究版本：`opening15_midpoint_half_position_research_v4`，与正式`opening15_midpoint_v7`共用Pine原文和本地映射。规则见[当前正式榜单](OPENING_POSITION_RANKING.md)。H/L为09:30–09:45高低点，M=(H+L)/2，W=(H−L)/2：

`X=(close−M)/W`

中点0、上沿+1、下沿−1，1单位是半宽。默认按abs(X)混合排序；多头X>0降序前十，空头X<0升序前十。不足十只不补齐。0不进候选。开仓方向仍按VWAP，不按X，09:45前不新开仓。

此前v1／v3为开盘价零轴，v2为中点零轴但使用完整宽度，均保留旧报告及完整源码。v4将排序和显示统一为中点／半宽，不能将旧报告改名伪装为新结果。Opening_From_Open仍记录开盘价净位移，作为历史比较辅助值，不参与新排名。

## 确认和数据完整性

- 区间从09:30统计至09:44一分钟，等价于09:30、09:35、09:40三根五分钟。09:45确认后固定，当日不再扩张。
- 正式数值09:45起可用；09:40不能套用事后完整15分钟的分母。研究命令拒绝09:45之前的确认时刻。
- 09:50榜单消费09:49一分钟K线收盘，不使用09:50刚形成的未收盘价格。
- 开盘窗口必须从09:30开始且无缺根，完整宽度须大于0；目标一分钟收盘必须存在。缺失时报告原因，不补造价格。
- 纯位置公式不依赖09:45之后的每根中间K线，因此中间缺少无关分钟不会阻挡该公式；同源VWAP基线仍按原严格连续性检查，不能静默忽略缺口。
- 一分钟Pine计算为权威；数据库同时有五分钟时，以前三根五分钟的O/H/L核对十五根一分钟的开盘和极值，不一致则排除并记录。
- 盘前盘后、昨收和夜盘不进入开盘零轴或区间。日期按America/New_York重置，处理夏令时。
- Pine图表在09:45之后的实时根内可随close变化，确认后才参与研究排名；实时重复报价不重复计数，不保留被修订当前根的旧极值。

## 源码和接口

Pine v6原文：[opening-range-position.pine](../indicators/opening-range-position.pine)。支持一分钟和五分钟图表，副图显示归一化位置、中点零轴及+1／−1边沿。

| ASCII plot | 含义 |
|---|---|
| Opening_Range_Position | X，未就绪或常规盘外为na |
| Opening_High_Position / Opening_Low_Position | 区间上下沿相对中点、除以半宽的坐标（+1／−1） |
| Opening_From_Open | 旧开盘价／完整宽度位置，仅辅助对比 |
| Opening_Centered_Position | 当前X，与主输出一致 |
| Opening_Midpoint | 锁定区间中点，完成前为na |
| Day_Open | 当天09:30开盘价，完成前为na |
| Opening_High / Opening_Low | 锁定区间高低点，完成前为na |
| Opening_Range_Width | 完整区间宽度，完成前为na |
| Range_Ready | 1为范围确认且合法，其他为0 |
| Position_Direction | 观察方向，1多、−1空、0中性或未就绪 |

保留六个公共执行字段作为安全占位：Entry_Signal、Direction恒为0，Entry_Price、Long_Stop、Short_Stop、ATR为na。没有入场条件、止损计划或执行授权，不注册到pine_strategies.json，不编造生产模型ID。

[研究计算器](../service/opening_position_research.js)使用现有createCalculator运行同一份Pine原文，无第二套Python指标公式。[数据库研究入口](../engine/opening_position_replay.py)只查本地研究归档，按确认时点截断后传给PineTS，不自动联网下载，不启动控制台或券商。

```sh
python -m engine.opening_position_replay --data-dir logs --day 2026-10-07 --at 09:50
```

默认使用命令执行时的股票池，沿用现有参考ETF与指数排除名单。全结果、多头前十long_top10、空头前十short_top10、方向数量side_counts、同一输入的VWAP纯位置基线和来源摘要返回JSON，同时将带版本ID的JSON／Markdown保存在logs/agent_research/experiments/。实验仅追加definition，不写实际ranking_batches、不修改执行账本，保留Pine源码哈希、计算器源码哈希、PineTS版本、股票池及输入内容哈希。每次研究同时归档Pine、计算器和读取器的完整源码，通过source_bundle_id关联，避免未提交的草稿升级后无法恢复旧公式。数据库缓存的最新修订用于事后因果重建，不等于历史当时实际接收到的数据。

## 如何判断是否改善

先比较同一分钟的前十变化、重点标的首次入榜和后续保留时间，再用多个日期和预先固定的评价窗口比较漏选、回撤及反例。单个时点将某只股票排得更高，不足以证明算法整体更好。该指标衡量相对区间中点的半宽距离，不等于趋势平滑度、速度或盈利概率；开盘范围特别小会放大得分，开盘范围特别大也会压低后续趋势的名次。目前仅记录这些限制，不自动加过滤或调整用户公式。

已用本地PineTS执行验证，**尚未在TradingView编辑器中实际编译验证**。没有修改用户浏览器中的指标。

隔离验证覆盖确认边界、完整宽度、开盘为零、中点不改变方向、方向榜独立排序及不足十只不补齐、多空镜像、价格尺度不变性、1m／5m对齐、开盘缺根、零宽、目标根缺失、盘前与未来数据隔离、实时修订、跨日与夏令时、参考标的排除，以及研究归档与真实榜单分离。测试仅使用合成行情与临时数据库；真实历史研究报告另外保存在本地，不提交用户数据。

## 绝对趋势

每个指数分别使用当时已确认的一分钟 close、同一分钟 VWAP±1σ、当时已确认的五分钟标准 EMA9：

| 状态 | 严格条件 |
|---|---|
| 绝对多头 | 一分钟 close > VWAP 上轨，且 close > 五分钟 EMA9 |
| 绝对空头 | 一分钟 close < VWAP 下轨，且 close < 五分钟 EMA9 |
| 非绝对趋势 | 数据有效但不满足以上任一状态，包含等于边界 |

规则启用时采用双指数共振：**两个指数同时绝对多头才禁止做空，同时绝对空头才禁止做多**。只有一个绝对趋势、两个状态相反或都在区间内时，这条规则不单独限制方向；其余准入条件仍全部检查。当前已暂停整道绝对趋势过滤。这里使用真实收盘价，不使用绘图平滑点 EMA3，也不预测未收盘 K 线。

## 大盘 TD

2026-11-24用户将大盘TD准入调整为“任意一个同向即可”。正式检查两个指数同一确认分钟的 TD（比较跨度4，显示着色阈值仍为±3）：

- 做多：NAS100 TD > 0 **或** SPX500 TD > 0。
- 做空：NAS100 TD < 0 **或** SPX500 TD < 0。
- 一正一负时，TD条件允许两个方向；一方为0时，另一方的正／负计数分别支持做多／做空；两者均为0时不放行。绝对趋势禁反向当前暂停。
- TD 缺失、重复、错分钟、错误周期契约或未收盘值均不能作为有效依据。

TD 开仓门槛为符号判断，无需等到±3。个股原有 TD≥1／≤−1、候选、风险、时效和保护检查继续叠加。趋势榜保留个股VWAP／EMA9过滤；[TD榜手动入口](TD_RANKING_VIEW.md)按用户确认取消个股位置过滤。两个指数的最新独立确认事实都须有效，且至少一个TD同向；不等待其他股票。

## 批次与证据

`service/market_rhythm.js`复用现有五分钟 EMA9 历史，为两个指数各附 `beta_ema9`：版本、周期9、300秒、K线开盘时间`time`、可知时刻`known_at`与`value`。只接受 `known_at=floor(as_of/300)*300`、`time=known_at−300` 的确认根，不借用更晚的 EMA9，也不以缺失值或相邻时间代替。

排名依据仍随`MarketRhythmReader`冻结；当前使用的指数TD按[独立确认通道](LIVE_CONFIRMED_TD.md)发布，界面与准入读取同一份观察值。整榜120秒拦截已取消，跨日及常规盘限制保留。绝对过滤启用时，缺少指数轨道、标准差或EMA9须等待；关闭时这些参考值不参与准入，但缺失、错误或未对齐的一分钟TD仍阻止新开仓，不能当作有效同向。

`execution/beta_admission.py`只比较现成指标及收盘事实，Python不另算 EMA／VWAP／TD。`execution/confirmed_td.py`供个股与指数共用 TD 字段校验。原 `execution.entry_admission.confirmed_td` 导入路径继续兼容。

准入快照使用 `beta_filter_required=true`、`beta_filter`（版本1、绝对趋势规则`both_indices_absolute`、TD规则`any_index_same_sign`、方向许可、拒绝原因和两指数证据）；快照ID与榜单绑定。旧`both_indices_same_sign`不能当成当前准入契约，旧页面须刷新、新服务须重启加载。订单的`candidate_admission.beta_evidence`保存实际发单前使用的规则和证据，不改写历史订单。分钟研究归档的指数`context`保留对应`beta_ema9`，原始K线、审计和订单数据继续保留。

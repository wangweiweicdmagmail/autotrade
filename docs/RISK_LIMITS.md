# 当前建仓风险限制

当前设置（2026-11-21）：

- 单次风险预算为 **1,000 美元**，由 `config.RISK_PER_TRADE_USD` 配置，界面只读。控制台手动单、候选榜市价单、开盘预约等入口按该预算定量；新启动执行实例的首仓使用该预算，后续建仓继续按所选执行配置的风险比例处理。
- 总剩余风险敞口默认上限为 **2,200 美元**，由 `RISK_MAX_TOTAL_RISK_USD` 配置；现有环境变量覆盖机制保留。保本后剩余风险的计算口径不变。
- 多头、空头各自的剩余风险上限为 **1,100美元**（`RISK_MAX_DIRECTION_RISK_USD`）。方向分别累计，不能多空抵消；待成交计划同样占用额度。一笔未保本订单实际占用1000美元风险时，同方向再开同规模订单会超过1100美元上限；按实际剩余风险检查，仓位封顶降低风险时不以固定笔数代替计算。已成交批次止损到成本或更有利时风险为0，释放额度后可再入场。这是风险金额限制，不是固定方向持仓笔数限制。
- 单只股票最大名义仓位为账户净值的 **140%**。订单管理模块按同一股票全部未结束批次合计检查，包含待成交数量，不用多空互抵绕过限制。单笔手动下单定量同时以该比例封顶；合计超限的新请求拒绝，不调整已有持仓。
- 同一股票已有未结束批次（包括待成交、持仓、正在平仓）时，拒绝再次手动市价建仓。全部结束后允许重新建仓；不是每天只能交易一次。自动策略自身的加仓规则独立保留，仍受总风险和单股仓位上限限制。

生产控制台向订单管理模块注入账户净值提供者，净值缺失时拒绝新建仓。单股仓位检查覆盖本系统订单账本中的批次，不能代替对账或保证券商外部未纳管仓位的额度。市价成交滑点和后续价格变动可能使成交后实际仓位比例偏离下单估算。

配置修改需重启服务生效；不会自动重设已运行执行实例的首仓风险、已下订单或已有仓位。通用 ST 转向及反向 FVG 仍仅提醒；候选订单另有用户明确选择的定时退出及 ST（10，3）跟踪规则，作用范围见下文。

## 候选与方向准入

全部新开仓统一限制在当前有效前十候选中，方向必须顺候选的已确认趋势。2026-11-22起，确认一分钟close同时高于VWAP中线和当时确认的五分钟EMA9才定义为多头，同时低于两者才定义为空头；介于两者之间或等于边界为中性，不进榜。发单前新鲜实时价也必须在确认VWAP中线与实时五分钟EMA9的同向侧；VWAP中线过滤不可关闭。还须满足已确认一分钟TD多头≥1、空头≤−1（含边界）；着色阈值仍为±3。多头实时观察价必须严格高于同根五分钟EMA9，空头必须严格低于，相等也拒绝。EMA读取真正9周期的`ts.ema_9`，不能用默认7周期的兼容字段代替。TD缺失或确认时刻错位不允许开仓。范围包含手动、自动策略首仓/加仓、黄金信号、小区间突破和开盘预约。生产订单管理模块在决策及发往券商前复核，不能通过ST方向、原震荡手选开关或force绕过。缺少有效当日常规盘榜单、确认超过120秒、数据缺口或未对齐时拒绝新开仓。

准入失败不撤销已受理订单、不改变现有仓位或保护单；离榜和方向反转不能因此自动平仓。订单快照保存候选名次和方向证据。历史回测不能使用当前榜单反推过去的准入结果，须另回放当时的候选数据。没有注入实盘候选检查的隔离测试环境保留旧ST方向模式，生产界面不提供反向手选入口。

## 手动初始止损选择

手动卡片可选默认五分钟 **2×ATR / 当前K线外** 或一分钟VWAP的 **1σ**：前者至少在当前五分钟K线极点外侧，后者由入场参考价向亏损方向偏移当前确认σ，不额外扩大到K线外侧。标准差缺失、非正或取整后止损不合法时拒绝。止损改变后按1000美元预算重新定量。仅手动订单使用该选择，自动及信号订单继续保留策略止损和原保本/退出规则，已有订单不重设。详见[宫格手动开单](MARKET_RHYTHM.md#宫格手动开单)。

## 候选持仓的共享保护

“候选与订单”左上角设置同时作用于已有候选持仓和后续候选订单；其他策略不变。默认排除入场分钟后计满五根一分钟K线，确认收盘后保本；到期已在成本或亏损侧时走专属市价退出。跟踪默认关闭，可选确认五分钟EMA9或一分钟ST（10，3），只收紧不放宽；仅启用ST跟踪的候选批次，在该确认ST反向时按用户授权退出。关闭跟踪或其他策略的ST反向仍只提醒。完整作用范围和未知结果处理见[候选保护规则](MARKET_RHYTHM.md#候选预订单的保本区间过滤与跟踪2026-11-21)。

## 外部长线持仓豁免

**当前豁免名单为空**（`config.EXTERNAL_ORDER_GUARD_EXEMPT_TICKERS = ()`）。用户已取消ANT的长线持仓豁免；ANT重新按普通股票适用外部订单守卫，在既有FA范围和归属核对条件下，外部挂单自动撤销、外部成交余仓自动平仓。控制台下发的订单继续按原有归属保护。

保留可配置豁免机制，主守卫的订单/持仓筛选、券商写操作前检查及旧清理/提醒模式共用同一名单。名单按股票代码精确匹配，接受`ANT`或`NASDAQ:ANT`形式，不按子串匹配其他股票。配置需要重启控制台加载，状态快照 `status.external_order_guard.exempt_tickers` 可核对实际加载名单。不改写执行账本、外部退出日志或券商历史，已提交给券商的委托不能因本地配置改动视为已撤销。

# TV 双布局客户端联动（0.8.0）

在客户端自己的Chrome分别打开两个独立TV窗口，另开控制台窗口。更新扩展后，在八格图表中选择“auto_trade 八格 · 席位3～10”并绑定；在六格图表中选择“auto_trade2 六格 · 四大盘与前两席”并绑定。保持同一AutoTrade控制台地址。八格和六格必须为不同标签页，跨窗口绑定仅授予绑定时唯一的控制台标签页；打开其他控制台副本需重新绑定，不借用已有跨窗口权限。

展示席位优先分给实际持仓，再填候选；同一股票不重复。候选名单每根一分钟K线收盘、完整批次收齐后更新一次；十分钟内保持位置，出榜原位替换。八格按上排9/7/5/3、下排10/8/6/4席位同步；六格按上排第1席/NAS100/SPX500、下排第2席/QQQ/SPY同步。两个布局分别回读，不因某个窗口不可用而切错另一个。成本/止损使用TV原生黄色/红色线段，均为只读图形，不创建模拟订单。

0.7.1保留切图时的时间视野，仅对变化的格子切换股票和恢复价格自动缩放；移除可能通过TV布局同步传播到其他宫格的`timeScaleReset`。控制台只向目标改变的窗口发送联动请求。权限没有变化，旧客户端更新扩展并在扩展管理页重新加载后生效。

0.8.0将`focus`改为两行三列六宫格。请更新扩展并重新加载；原绑定地址不变，权限不增加。旧四格和三行两列的旧六格会拒绝联动，避免把参考指数切成候选股。

以下保留原安装说明；单标的联动仍只操作八格的第六格。

# AutoTrade 客户端图表联动

每个局域网客户端独立绑定自己浏览器里的 TradingView 图表标签页。客户端在交易运维控制台点选标的时，本机扩展使用 Chrome DevTools Protocol 切换图表并核对读回的标的。

1. 用客户端 Chrome 登录 AutoTrade。页面会检测扩展，首次缺失时尝试下载 ZIP 并打开安装指引。也可以从「连接本机图表」重新下载。
2. 解压 ZIP。在 Chrome 地址栏打开 `chrome://extensions`，开启开发者模式，点「加载已解压的扩展程序」，选择解压后的 `autotrade-tv` 文件夹。
3. 打开自己的 TradingView 图表。从 Chrome 工具栏的拼图图标打开「AutoTrade TradingView 联动」，点「绑定当前图表」，允许扩展访问页面预填的控制台地址。
4. 回到 AutoTrade，看到「本机图表已连接」后点击股票代码。控制台会显示本机图表确认的标的。

从源码目录直接加载时，需要在扩展里填写控制台地址。已安装早期测试版的浏览器可从扩展管理页移除测试版，再使用控制台下载的包。

每个浏览器绑定一个控制台地址。点击股票时，扩展优先查找该AutoTrade标签页同窗口的图表。绑定时若该控制台地址只有一个标签页，会同时记录它的ID；这个明确绑定的标签页也可使用另一个窗口的TV，其他控制台标签页不能借用跨窗口绑定。当前窗口有多个候选时可分屏或绑定其中一个。TV 使用两行四列八宫格；所有单标的切换仍固定使用视觉行优先第六格（下排第2列），其他七格保持原标的。布局不符或单图最大化会提示调整，不切到第一格。重启 Chrome 或更改已绑定标签页的布局地址后，在目标标签页重新绑定。扩展使用 Chrome 自带的本机调试接口，支持 TradingView 国际站和中文站。

联动时 Chrome 可能显示调试提示。CDP 在读回结果后断开。继续使用主机自己的控制台时，主机图表由现有服务端流程控制。

## 双客户端验收

两台客户端分别按上面的流程绑定自己的 TradingView 标签页，记下主机图表的当前标的。两台客户端同时点选不同标的，确认各自图表和控制台读回提示一致，再核对主机图表的标的。

## 0.4.0：六格联动与成交标记

更新后刷新 AutoTrade。六宫格页会同步到本客户端已绑定的同窗口 TV 两列三行布局，逐格回读，仅更新变化的标的。两个指数保持完整数据商代码，股票允许BATS前缀归一化。标记由 AutoTrade 已确认成交生成，使用 TV 原生箭头；不会向 Paper Trading 提交订单或修改实盘保护单。扩展权限与0.3.0相同。

## 0.5.0：单标的统一切换第六格

更新扩展文件后，在 `chrome://extensions` 点击本扩展的重新加载，再刷新 AutoTrade。VWAP 分布图、订单批次、信号流等所有股票链接都切换 TV 右下角第六格，并核对读回结果。旧扩展会收到更新提示，不能继续按旧规则切第一格。完整六格同步仍逐格对应；请关闭 TV 的标的同步分组，避免 TV 自身带动其他图格切换。扩展权限没有变化。

## 0.6.0：控制台四格与TV八格

更新扩展后重新加载并刷新AutoTrade。控制台四格显示NAS100、SPX500、候选第1名和第2名。TV上排从左到右显示第9、7、5、3名，下排显示第10、8、6、4名，按当前榜单自动更新。图表必须设置为两行四列，关闭单图最大化。共享几何定位逐格核对，不按TV内部创建顺序排列。旧扩展会提示更新；权限不变。单标的点击继续使用第六格，完整同步可恢复排名布局。
